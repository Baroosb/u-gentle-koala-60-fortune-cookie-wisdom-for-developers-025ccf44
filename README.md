One fortune-cookie line for a software developer, 75 characters: "Every estimate you give in the morning is a letter to a stranger by Friday." The line lives in `entry.txt`; `main.py` copies it byte-for-byte to the output as `/output/entry.txt`. The line was picked by a candidate tournament judged pairwise against the bounty's published judge brief.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
